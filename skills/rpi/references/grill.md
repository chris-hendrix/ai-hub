# Grill

Interview the user relentlessly about a plan or design until you're confident no consequential question remains unasked.

- One question at a time. Offer your own position with each, so the user reacts instead of composes.
- Check the codebase before asking — never ask what you can read yourself.
- Keep going until you could predict the user's answer to any "why" or "how" about the plan, and they'd say "yes, exactly" if it were explained back.
- Nothing is written — alignment is the output.
